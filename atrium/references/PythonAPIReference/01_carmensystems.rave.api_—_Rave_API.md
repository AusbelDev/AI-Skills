*class* `carmensystems.rave.api.``foreach`(*iteration*, *\*evaluators*)
:   \_\_init\_\_(self, iteration, evaluators)

    An *evaluator* that uses an [`Iteration`](stubs/carmensystems.rave.api.Iteration.html#carmensystems.rave.api.Iteration "carmensystems.rave.api.Iteration") to produce a whole batch of *Rave value* s and other data.

    The value returned when evaluating a foreach is a list of tuples, one tuple for each evaluation of the constructor arguments. The size of each tuple is the same as the number of arguments given to the constructor, and each slot in the tuple contains evaluation results from the corresponding argument. The first slot – the [`Iteration`](stubs/carmensystems.rave.api.Iteration.html#carmensystems.rave.api.Iteration "carmensystems.rave.api.Iteration")’s slot – holds a [`LoopData`](stubs/carmensystems.rave.api.LoopData.html#carmensystems.rave.api.LoopData "carmensystems.rave.api.LoopData") object, the others contain the value returned from the corresponding *evaluator* .

    |  |  |
    | --- | --- |
    | Parameters: | * **iteration** ([`Iteration`](stubs/carmensystems.rave.api.Iteration.html#carmensystems.rave.api.Iteration "carmensystems.rave.api.Iteration") or `string`) – specifies what to iterate over and how output is sorted. If the argument is a string, the result of calling [`iter`](stubs/carmensystems.rave.api.iter.html#carmensystems.rave.api.iter "carmensystems.rave.api.iter")(**iteration** ) will be used. * **evaluators** (*evaluator* s) – items to evaluate on all objects iterated over. The *dependency level* of each evaluator must match the level given by the iteration. |

    `__init__`()

    |  |  |
    | --- | --- |
    | Parameters: | * **iteration** ([*Iteration*](stubs/carmensystems.rave.api.Iteration.html#carmensystems.rave.api.Iteration "carmensystems.rave.api.Iteration") *or* *string*) – specifies what to iterate over and how output is sorted.   If the argument is a string, the result of calling   `iter(iteration)` will be used. * **evaluators** (*evaluators*) – items to evaluate on all objects iterated over.   The *dependency level* of each evaluator must match the   level given by the iteration. |
