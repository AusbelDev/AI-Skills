AbsTime, RelTime, and AbsDate are Python modules generated by SWIG from C++. In the C++ source code there are docstrings that are possible to reuse in Python. Currently, this does not work. The steps needed to set this up are described here: <https://jira.jeppesensystems.com/confluence/display/PDOLD/Documenting+Python+modules>.

This module contains one class, [`AbsTime`](#module-AbsTime "AbsTime"), that defines absolute times.

The AbsTime represents time-points with a granularity of 1 minute. AbsTimes range from
start of the `FIRST_OK_ABSTIME` to `LAST_OK_ABSTIME`; currently this range is 01jan1872
00:00 .. 31dec2099 23:59. Minutes are normalized around `EPOCH` (1 Jan 1986 00:00), i.e.,
positive minutes represent dates later than EPOCH and negative minutes dates earlier
than EPOCH. Dates from EPOCH and forward are compatible with the old CarmTime.

The AbsTime class defines a binary and a text representation. The binary representation is
compatible with the old CarmTime and Rave. The text representation is compatible with
Rave. This class also provides all necessary operators for making computations and
comparisons on absolute times.

See also: [`AbsDate`](absdate.html#module-AbsDate "AbsDate"), [`RelTime`](reltime.html#module-RelTime "RelTime").
