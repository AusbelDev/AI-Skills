    `bind`()
    :   Return a copy of this definition with one of its arguments bound to a given value. The argument is specified by its position (starting from 1).
        Examples:

        ```
        c = ruleset.get... 
        # Bind two arguments 
        bound = c.bind(1, value1).bind(2, value2) 
        # Change the first argument 
        bound = bound.bind(1, value3)
        ```

        The method does not check the argument in any way. For performance reasons this is deferred to evaluation time. Rave does not accept void values as arguments, so binding an argument to void is equivalent to not binding it at all, or “unsetting” it if it was already bound to a proper value.

        |  |  |
        | --- | --- |
        | Parameters: | **position** ([*int*](https://docs.python.org/2.7/library/functions.html#int "(in Python v2.7)")) – the argument position. |
        | Returns: | a new instance bound to the given argument. |
        | Raises: | **ValueError** – if the given argument position is not in the range [1, number-of-parameters]. |
