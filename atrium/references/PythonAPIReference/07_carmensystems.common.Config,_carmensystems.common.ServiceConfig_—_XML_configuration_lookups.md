# carmensystems.common.Config, carmensystems.common.ServiceConfig — XML configuration lookups


There are two modules:

* [`carmensystems.common.Config`](api.html#module-carmensystems.common.Config "carmensystems.common.Config"): contains a base class ([`Config`](api.html#carmensystems.common.Config.Config "carmensystems.common.Config.Config")) that provides basic access to configuration properties.
* [`carmensystems.common.ServiceConfig`](api.html#module-carmensystems.common.ServiceConfig "carmensystems.common.ServiceConfig"): contains one class ([`ServiceConfig`](api.html#carmensystems.common.ServiceConfig.ServiceConfig "carmensystems.common.ServiceConfig.ServiceConfig")) that extends [`Config`](api.html#carmensystems.common.Config.Config "carmensystems.common.Config.Config") with service functions.

There is also a command line interface: [${CARMSYS}/bin/xmlconfig](xmlconfig.html#xmlconfig).

* [API reference](api.html)
* [xmlconfig — Configuration lookup tool](xmlconfig.html)

A corresponding Java API is available in the `com.jeppesen.jcms.config` package.
