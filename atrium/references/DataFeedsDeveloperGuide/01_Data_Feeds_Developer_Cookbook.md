# Data Feeds Developer Cookbook


This section provides step-by-step guides and instructions for data feeds developers.

[Creating a standalone custom interface](devbook/interfaces_custom.html#interfaces-custom) describes how to develop a custom request/response data feed without the Interface Builder

[Creating a trigger service](devbook/interfaces_triggers.html#interfaces-triggers) describes how to develop a trigger.

The [Integrator](integrator-core/index.html#ifbld-index) chapter describes how to make services inside JCMS available to external systems using the Integrator component.

The [Jobrunner Configuration Guide](jobrunner.doc/index.html#jobrunner-conf-guide) describes how to configure the Jobrunner framework, for scheduling and triggering of e.g. datafeeds imports and exports.

[Setup of processes and services](setup_interfaces/index.html#datafeeds-setup-interfaces) describes concrete realizations of typical interfaces and the
reasoning behind the design decisions. This includes cases that utilize the standard interfaces as well as
custom feeds and services.
