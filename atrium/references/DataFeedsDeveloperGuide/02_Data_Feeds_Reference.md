# Data Feeds Reference


This section of the Data Feeds Developer Guide contains reference material for the core system components:

The [IOServer](ioserver/main/index.html#ioserver-index) chapter provides documentation of the IOServer framework itself and the APIs it
provides for plugin development and test support.

The [SMOG](smog.doc/index.html#smog-index) chapter provides documentation of the Service Model Object Generator tool that can be
used for developing services.

The [Standard Interfaces](std_interfaces/index.html#stdif-index) chapter describes the existing standard interfaces.

The [Synchronize Data between Atrium systems](syncadata.doc/index.html#syncadata-conf-guide) chapter describes the syncadata component that keeps data synchronized across Atrium systems deployed at the same site.

The pohlman-conf-guide chapter describes Jeppesen Weather Service.
