> Modules
>
> Rave obtains its information from a set of input files written in accordance with this reference. Several such files are compiled to a single rule set, and each file contains a sequence of definitions. A definition can define a variable, function, table, rule set, etc., see[Definitions](Definitions.06.01.html#21840 "Definitions").
>
> To give the rule set a structure, definitions are grouped into modules where each module can have its own specific task. The module system also makes it easier to share definitions between different rule sets.
