> Threads
>
> Rave can run several computations in parallel using thread-safe technology, when used in applications that support this option (currently Crew Pairing Optimizer). To enable this feature for Crew Pairing Optimizer you should set the CRS resourceapc.RaveCompile.ThreadSafe to true.
>
> |  |  |
> | --- | --- |
> | Note | Threads/parallel execution and Rave Profiler cannot be used at the same time. Rave Profiler currently needs to run in single-threaded execution. |
