> Tools
>
> Rave includes the following powerful tool.
>
> Rave Profiler
>
> Rave Profiler is an analysis tool that measures how the execution time is spent in the Rave code and counts the number of calls to the different rules and variables. It also shows which variables that are cached and the cache hit rate. All these properties are useful to better understand the execution of the Rave code and to find the bottlenecks.
>
> Rave Profiler is used for analyzing optimization runs, as well as any GUI operation in Studio or report generation. To enable it, you compile the rule set with the Profiling option. Rave Profiler can be started from Developer Workspace or Studio to track any manual operation, while profiling data from optimization runs are saved automatically (in$(CARMTMP)/RaveProfiling) when the run is finished.
>
> The information from Rave Profiler is displayed as a flow chart in Developer Workspace.
