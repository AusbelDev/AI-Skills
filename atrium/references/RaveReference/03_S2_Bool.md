> Bool
>
> The boolean type has only two possible values:true or false. Booleans are used to represent logical states, that is whether a certain condition is fulfilled or not.
>
> Syntax
>
> |  |  |  |
> | --- | --- | --- |
> | data\_type | ::= | bool |
> | bool\_const | ::= | true | false |
