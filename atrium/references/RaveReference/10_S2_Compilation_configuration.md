> Compilation configuration
>
> The compilation options are controlled by a script where you configure available applications, Rave source path, etc. In a Crew & Ops Management solution this script will use the CRS resource system to find the options and there should usually be no need of changing these CRS resources. Rave as stand-alone product has the configuration options coded directly in this configuration script by default and the default script also has documentation of the available options.
