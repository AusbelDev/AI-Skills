> Module dependencies
>
> No circular import dependencies for the module implementations are allowed in a rule set. The structure can basically be viewed as a tree with the most basic definitions in its leaves.
>
> ![](images/Module_dependencies.png)
>
> If necessary, two modules can be dependent of each other via pure interface modules. It is not recommended to use this functionality more than necessary since it may give a bad structure of the rule set.
>
> ![](images/Multiple_implementations2.png)
