> Appendix: Modelling information
>
> This appendix gives information that is useful for developers when modelling with Rave and working with performance.
>
> It is important to follow up on the performance regularly when modifying Rave code. Performance problems detected and addressed at an early stage are much easier to solve than removing bottlenecks later on.
>
> A useful tool when analyzing Rave code is[Rave Profiler](Tools.html#22072 "Tools"), which gives a view of the internal function calls in the Rave code.
