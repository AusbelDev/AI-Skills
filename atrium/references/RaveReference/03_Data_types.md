> Data types
>
> Rave has five predefined data types:[Int](Data_Types.04.2.html#21858 "Int"), [Bool](Data_Types.04.3.html#21877 "Bool"), [String](Data_Types.04.4.html#24932 "String"), [Reltime](Data_Types.04.5.html#26209 "Reltime") and [Abstime](Data_Types.04.6.html#21957 "Abstime"). The language also supports user-defined enumeration types. For each type there is a syntax for specifying the type itself and for expressing constants of the type. There are also built-in functions, operators and keywords allowing various computations to be performed on each type.
>
> Rave enforces strict type checking, which assists the Rave programmer in detecting some types of errors. Type checking means that types cannot be mixed freely in expressions. For instance, an integer cannot be added to a time, since integer and time represent different entities and adding them is generally not a useful operation. Each operation and built-in function defines what specific combinations of data types it allows.
