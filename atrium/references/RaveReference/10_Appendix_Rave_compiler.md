> Appendix: Rave compiler
>
> This appendix describes the Rave compiler and is mainly intended for programmers using the Rave stand-alone product.
>
> The Rave compiler,ccrc, is accessed with the compilation script rave\_compile. It sequentially runs the Rave compiler, the C compiler and linker to create a rule set that can be loaded by a specific application.
