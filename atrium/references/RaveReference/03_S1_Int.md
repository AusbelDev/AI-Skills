> Int
>
> The integer type is used to represent positive and negative numbers. The range is -2,147,483,648 to +2,147,483,647 and integers should stay within this range to avoid undefined behaviour. Please note that no error is raised for integers outside the range.
>
> There is no floating point type. Fractional numbers can usually be represented by integers, for example as percentages.
>
> Syntax
>
> |  |  |  |
> | --- | --- | --- |
> | data\_type | ::= | int |
> | int\_const | ::= | one or more digits,0-9 |
