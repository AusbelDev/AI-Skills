> String
>
> Strings are (unlike all other parts of the language) case-sensitive.
>
> |  |  |
> | --- | --- |
> | Example | "String1" and "string1" are not equal  (Furthermore "String1" < "string1" holds true) |
>
> Syntax
>
> |  |  |  |
> | --- | --- | --- |
> | data\_type | ::= | string |
> | string\_const | ::= | string+ |
> | string | ::= | A sequence of characters delimited by" (double quotation marks).  All printable ISO-8859-1 (Latin-1) or UTF-8 characters except", \, and newline, can be used in string literals.  The following escape sequences are also allowed:  |  |  | | --- | --- | | • | \" (literal double quotation mark) |  |  |  | | --- | --- | | • | \\ (literal backslash) |  |  |  | | --- | --- | | • | \n (newline) |  |  |  | | --- | --- | | • | \t (tab) | |
