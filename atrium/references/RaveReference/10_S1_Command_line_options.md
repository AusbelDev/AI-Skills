> Command line options
>
> The Rave compilation scriptrave\_compile has a number of command line options. The options are displayed by executing the script with no arguments.
>
> An example on howrave\_compile can be run is this:
>
> |  |  |
> | --- | --- |
> | Example | rave\_compile gpc -optimize cabin\_rules |
>
> This would compile the rule setcabin\_rules for an application called gpc.
>
> Which applications that are available and how the rule set should be compiled is described by the configuration.
