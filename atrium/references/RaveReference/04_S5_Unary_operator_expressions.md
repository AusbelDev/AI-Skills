> Unary operator expressions
>
> Syntax
>
> |  |  |  |
> | --- | --- | --- |
> | expr | ::= | + expr |- expr |not expr |
>
> where
>
> |  |  |
> | --- | --- |
> | + | takes an integer or reltime operand and returns the value, in practice it does nothing. The result has the same type as the argument. |
> | - | takes an integer or reltime operand and returns the negative value. The result has the same type as the argument. |
> | not | takes a boolean operand and returns a boolean value that is the logical negation of the operand. |
